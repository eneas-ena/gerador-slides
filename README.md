# Gerador de Apresentações

Transforma um documento em Word (.docx) numa apresentação editável em PowerPoint — Igreja Vidas.

**Abrir o app:** https://eneas-ena.github.io/gerador-slides/

## Como funciona

- App feito em página web; pode ser instalado na tela inicial do iPad, iPhone ou Mac.
- Os dados ficam salvos só no próprio aparelho (não sincronizam entre aparelhos).
- Os serviços externos, como a inteligência artificial, passam pelo Worker `gerador-slides` no Cloudflare; as chaves secretas ficam guardadas lá, nunca neste código.

## Como publicar uma nova versão

1. Nesta página do repositório, clique em **Add file → Upload files**.
2. Arraste os arquivos novos, com os mesmos nomes dos antigos.
3. Clique em **Commit changes**.

Em um ou dois minutos a nova versão está no ar no mesmo endereço.
